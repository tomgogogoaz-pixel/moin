# Moin web fonts

## SUIT Variable

- Source: https://github.com/sun-typeface/SUIT
- File: `SUIT-Variable.woff2`
- License: SIL Open Font License 1.1 (`SUIT-LICENSE.txt`)
- Usage: Latin letters, numbers, and related punctuation through CSS `unicode-range`

## Pretendard Variable

- Source: https://github.com/orioncactus/pretendard
- Version: 1.3.9
- File: `PretendardVariable.woff2`
- License: SIL Open Font License 1.1

Both fonts are self-hosted under Moin's local-only Content Security Policy. SUIT Variable is the active global typeface for Korean and Latin; Pretendard remains bundled only as an inactive fallback asset.
